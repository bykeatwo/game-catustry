# Sub-Plan 1: Scaffold & Toolchain — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up the TypeScript + Vite + Phaser 3 + Vitest toolchain and a blank isometric scene with a keyboard-movable cat sprite.

**Architecture:** A Vite project that boots a Phaser 3 game. Phaser renders a flat isometric diamond-tile ground and a placeholder cat sprite moved with WASD/arrow keys. A separate `src/domain/` folder is reserved (empty for now) for the pure, testable game logic built in Sub-Plan 2. `src/presentation/` holds Phaser scenes; `src/config/` holds shared constants.

**Tech Stack:** TypeScript, Vite 5, Phaser 3.80, Vitest 1, Node ≥ 20, npm ≥ 10.

**Spec:** `docs/superpowers/specs/2026-09-11-open-world-settler-design.md`

## Global Constraints

- Node ≥ 20, npm ≥ 10.
- TypeScript strict mode; no `any` leaks except where Phaser types force it (keep to a minimum).
- Vanilla TypeScript + Phaser only — no React, no other UI framework, no backend.
- Domain code (`src/domain/`) must never import Phaser or any DOM/Phaser type.
- Persistence uses `localStorage` (built in Sub-Plan 5); no DB.
- Deferred out of MVP: guild, medals, gear, backend, win-state.

```ts
export function isoToScreen(gx: number, gy: number, tw: number, th: number) {
  return { x: (gx - gy) * (tw / 2), y: (gx + gy) * (th / 2) };
}

export function screenToIso(sx: number, sy: number, tw: number, th: number) {
  return {
    gx: (sx / (tw / 2) + sy / (th / 2)) / 2,
    gy: (sy / (th / 2) - sx / (tw / 2)) / 2
  };
}
```

- [ ] **Step 3: Write `src/presentation/GameScene.ts`**

```ts
import Phaser from 'phaser';
import { GAME_CONFIG } from '../config/gameConfig';
import { isoToScreen } from './iso';

export class GameScene extends Phaser.Scene {
  private cat!: Phaser.GameObjects.Sprite;
  private cursors!: Phaser.Types.Input.Keyboard.CursorKeys;
  private wasd!: Record<'W' | 'A' | 'S' | 'D', Phaser.Input.Keyboard.Key>;

  constructor() { super('GameScene'); }

  create(): void {
    this.drawIsoGround();
    this.cat = this.createCat();
    const kb = this.input.keyboard!;
    this.cursors = kb.createCursorKeys();
    this.wasd = kb.addKeys('W,A,S,D') as this['wasd'];
  }

  private drawIsoGround(): void {
    const { tileWidth: tw, tileHeight: th } = GAME_CONFIG;
    const g = this.add.graphics();
    for (let gx = 0; gx < 12; gx++) {
      for (let gy = 0; gy < 12; gy++) {
        const { x, y } = isoToScreen(gx, gy, tw, th);
        g.fillStyle((gx + gy) % 2 === 0 ? 0x6a9a54 : 0x5c8a48, 1);
        g.beginPath();
        g.moveTo(x, y - th / 2);
        g.lineTo(x + tw / 2, y);
        g.lineTo(x, y + th / 2);
        g.lineTo(x - tw / 2, y);
        g.closePath();
        g.fillPath();
      }
    }
  }

  private createCat(): Phaser.GameObjects.Sprite {
    if (!this.textures.exists('cat')) {
      const tmp = this.add.graphics();
      tmp.fillStyle(0xffaa33, 1);
      tmp.fillCircle(16, 16, 12);
      tmp.generateTexture('cat', 32, 32);
      tmp.destroy();
    }
    const start = isoToScreen(1, 1, GAME_CONFIG.tileWidth, GAME_CONFIG.tileHeight);
    const cat = this.add.sprite(start.x, start.y, 'cat');
    cat.setDepth(10);
    return cat;
  }

  update(_time: number, delta: number): void {
    let dx = 0, dy = 0;
    if (this.cursors.left.isDown || this.wasd.A.isDown) dx -= 1;
    if (this.cursors.right.isDown || this.wasd.D.isDown) dx += 1;
    if (this.cursors.up.isDown || this.wasd.W.isDown) dy -= 1;
    if (this.cursors.down.isDown || this.wasd.S.isDown) dy += 1;
    const len = Math.hypot(dx, dy);
    if (len > 0) {
      const step = (GAME_CONFIG.playerSpeed * delta) / 1000 / len;
      this.cat.x += dx * step;
      this.cat.y += dy * step;
    }
    this.cat.setDepth(this.cat.y); // depth so the cat sorts vs future objects
  }
}
```
